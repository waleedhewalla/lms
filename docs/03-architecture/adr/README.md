# ADRs — Architecture Decision Records

Location: `docs/03-architecture/adr/`. Format: `NNNN-short-title.md` with Status / Context / Decision / Consequences.
Numbering is sequential; never reuse numbers. Statuses: proposed → accepted → deprecated | superseded-by-NNNN.

An ADR is required before code for: stack/framework changes, data-store choices,
auth/security model changes, deployment topology, integration patterns, AI model/data-source choices.
Trivial version bumps do not need ADRs.
